Step 1 — Generate Key Pair

One-time setup

Generate an Ed25519 key pair. Do this once per app, then save the private key to a secure location (password manager, encrypted vault). The public key is embedded in licenseValidator.js and is safe to ship with your app.

⚠ Never commit private.key to version control or include it in your app bundle. Anyone with this key can generate unlimited valid licenses. Store it in an encrypted vault (1Password, Bitwarden, macOS Keychain, etc.)
